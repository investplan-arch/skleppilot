# SklepPilot — strona sprzedażowa + sklep demo

Gotowy pakiet startowy:
- `index.html` — landing page usługi
- `styles.css` — pełny responsive design
- `script.js` — formularz leadowy przez `mailto:`
- `privacy.html` — ROBOCZY szablon polityki prywatności
- `demo/index.html` — demonstracyjny sklep „Nord Atelier”

## Przed publikacją — obowiązkowo

1. Kup i potwierdź domenę `skleppilot.pl` lub zmień nazwę/domenę w plikach.
2. Utwórz skrzynkę `kontakt@skleppilot.pl`.
3. W `script.js` ustaw rzeczywisty adres odbiorcy.
4. Uzupełnij w stopce i `privacy.html`:
   - pełną nazwę przedsiębiorcy,
   - NIP,
   - adres,
   - e-mail.
5. Zweryfikuj politykę prywatności względem faktycznie używanego hostingu, formularza, analityki i cookies.
6. Jeśli instalujesz GA4 / Meta Pixel — wdroż mechanizm zgód cookies przed uruchomieniem tych skryptów.
7. Pakiety i ceny traktuj jako ofertę startową — dostosuj zakres do technologii, na której faktycznie będziesz wdrażać sklepy.

## Publikacja za 0 zł
Pliki są statyczne i mogą być hostowane np. na GitHub Pages, Cloudflare Pages lub Vercel.

## Dlaczego demo jest oznaczone jako demo
Nie pokazujemy fikcyjnej realizacji jako prawdziwego klienta. To celowo transparentna koncepcja demonstracyjna do pierwszej sprzedaży.
